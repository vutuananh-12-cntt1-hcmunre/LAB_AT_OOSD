# Hệ thống quản lý khách sạn

Đây là hệ thống quản lý khách sạn được xây dựng bằng **Spring Boot, Thymeleaf, Spring Data JPA và SQL Server**.

## Chức năng
- Quản lý khu vực, phòng, tiện nghi.
- Quản lý nhân viên, khách hàng.
- Quản lý đặt phòng và người lưu trú.
- Quản lý sử dụng dịch vụ.
- Quản lý đền bù.
- Quản lý hóa đơn và thanh toán.
- Thống kê.

## Công nghệ
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- Thymeleaf
- HTML / CSS
- Microsoft SQL Server
- Maven

## Tiến độ
-Kết nối cơ sở dữ liệu.
-Xây dựng Entity, Repository, Service, Controller.
-Hoàn thành các form giao diện chính.
-Hoàn thành trang chủ và menu chức năng.
-Hoàn thành file Word mô tả/thiết kế giao diện.
-Kết nối csdl vào form
