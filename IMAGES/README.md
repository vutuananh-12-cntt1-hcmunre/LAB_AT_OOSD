Thư mục này chứa tổng hợp các sơ đồ thiết kế (UML, Draw.io,...) phục vụ cho **8 bài lab** trong đồ án.

* **Định dạng:** Các file hình ảnh uml,draw.io đại diện cho từng phần bài tập thực hành.
